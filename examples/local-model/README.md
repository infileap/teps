# 一份真的会说话的技能

这个目录里没有桩。`main.py` 起本机的 llama.cpp，把提示词送进去，把模型的回答打到标准输出；`run.sh` 把它**发布成一份技能**、通过内核跑一遍、让核验器判定，并把结果提级。

## 怎么跑

```sh
tools/install_llama.sh     # 装运行时（llama.cpp b11617，16 MB，钉死 sha256）
bash examples/local-model/run.sh
```

模型 `/mnt/d/models/qwen2.5-7b-instruct-q3_k_m.gguf`（3.8 GB）不在仓库里：它是**数据不是代码**。

## 实测

| 量 | 值 |
|---|---|
| 冷加载 | ~93 秒 |
| 一次调用（8 token，含加载） | **~160 秒** |
| `observed.latency_ms` | **159001** |
| `observed.stdout` | `{"answer": "PONG"}` |
| 核验器判定 | `ok`（`verified_by: verify_assert`） |
| 必败用例 | **`held: true`** —— 它有能力失败 |
| 提级 | **E1**（双边证据齐了） |

## 三条不显然的地方

### 1. 模型与运行时的路径钉在载荷的字节里

载荷的字节**就是**技能的身份。所以路径必须钉在字节里，而它们指向本机——这份载荷**换一台机器就不可复现**。

那是实话，而它由**哈希链**记着，不由注释承诺着。一条不可复现的载荷仍然可以是一份诚实的技能，只要它不假装自己是可复现的。

### 2. 一个自由发挥的回答没法断言

所以提示词被约束成有唯一可查答案的形式（「Reply with exactly: PONG」），断言查的就是那串字符。

> **你能断言的是一个「受限的」回答，不是一个「好的」回答。**

### 3. 它必须有能力失败

输入里带 `"refute": true` 时它故意退出 3。没有这一条，一个永远返回成功的载荷和一份正确的声明**长得一模一样**——那正是 `verify_refute` 存在的理由。

## 为什么它不接进 `check_all.sh`

**它慢**：一次调用约 160 秒。

> 一条要跑三分钟的守卫会被从默认路径里拿掉，**然后就没有人跑它了**。

所以它是一条**明确按需跑**的演示，不是守卫。这与 `tools/check_provenance.py` 是同一条纪律的两面：那里是「一台跑不了的守卫不是守卫」，这里是「一台太慢的守卫也会变成没有守卫」。

## 常驻：`resident.py` + `resident.sh`

上面那一份每问一次起一个 `llama-cli`，于是每问一次重读一遍 3.8 GB。`resident.py` 连一个**已经在跑**的 `llama-server`，加载只发生一次。

```sh
bash examples/local-model/resident.sh
```

| 量 | 每问一次起一个进程 | 常驻 |
|---|---|---|
| 加载 | 每次约 93 秒 | **一次 33 秒** |
| 第一次调用 | 约 160 秒 | **4 秒** |
| 第二次调用 | 约 160 秒 | **1 秒** |

### 它发布不成技能，直到 `env.reaches` 出现

旧规则里 `env.network` 是**一个布尔值**，而它把两件不同的事合成了一件：

- 连**远端主机**：答案取决于它今天说什么 ⇒ 不可复现，该拒
- 连**本机套接字**：它背后的东西是本机状态的一部分，**由自己的字节钉住** ⇒ 可复现，该放行

`env.reaches` 就是那条分界线：`{socket, artifact}`，只许回环，且**必须**给出套接字背后那个东西的哈希。

```json
"env": {
  "interpreter": "/usr/bin/python3",
  "reaches": [{"socket": "tcp:127.0.0.1:18911",
               "artifact": "a96b16179dc6cc9afdf0cf7a96a80c199cbd00b9be207c3465be21cb721cca5e"}]
}
```

那个哈希是 `sha256sum /mnt/d/models/qwen2.5-7b-instruct-q3_k_m.gguf` **实测**出来的，不是抄的。它是**声明**——商店核不了那个文件（它在商店之外）——但它把「本机」从一个形容词变成了一条可以复核的句子。

### ★ 声明与载荷必须说的是同一个套接字

`resident.sh` 声明连 `tcp:127.0.0.1:18911`，`resident.py` 连 `http://127.0.0.1:18911`。

**分开了的话两个都会「通过」**：商店只核清单，载荷只连它自己那个地址。所以 `tools/check_examples.py` 专门核这一条，`socket` 与载荷里的 `SOCKET` 必须对得上。
