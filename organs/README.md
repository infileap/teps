# organs/ —— 外设

**内核之外的一切判断力都在这里。** 器官可以摘换：装上是一个实现，换下是另一个实现，内核一行不改。

## 为什么这些东西不在内核里

它们**全部**在同一个测试上失败：**它们是纯函数。**

| 外设 | 为什么它不配进内核 |
|---|---|
| 仲裁器（opex + capex） | 输入是状态快照，输出是决策。纯函数。 |
| 上下文合成器 | 挑候选、打分、填预算。纯函数。 |
| **核验器** | 按 `verify.assert` 独立判定 outcome。纯函数。 |
| 记忆 / 索引 | 可重算。丢了能重建。 |
| 技能店 | 文件系统 + 协议。 |
| 算力池注册表 | 一张表。 |
| HTTP 传输 | 进程，不是盘上格式。 |
| 脚本宿主监督 | 超时与熔断策略。 |
| 停滞计数器 stall/repeat/waste | 观测，不是权威。 |

**"纯函数"意味着：同样的输入给同样的输出，不需要唯一权威、不需要原子、不需要每次经过。**
所以它们不需要进内核——这不是妥协，这正是它们该待的地方。

## 一条关键推论

**核验器在外设里，所以内核不管真实性。**

内核只保证**完整性**：记录没被改过、顺序没被换过、链没断过。
它不认识"技能""策略""增益"——**它不可能管真实性，因为它连这些词都不许有。**

（这是本文档对上一条设计的一处修正：早先想写"链管完整性，内核管真实性"。
按"内核必须微小"的约束，后半句必须改掉。）

## 契约不变

外设与内核之间**只有协议**（[../docs/CONTRACT.md](../docs/CONTRACT.md)）。
外设之间不直接调用；它们通过内核的日志与协议交换状态。
**这条是"器官可摘换"的全部保证**——一旦两个外设互相 import，它们就长在一起了。

### `session/` —— 第一个实现了的器官

`state.go` 是一张 `map[State]map[Event]State` 转移表；`guards.go` 是四个纯计数判据
（停滞 / 循环 / 浪费 / 同策略重试）；`machine.go` 把它们组装成一个值。

**它的"纯"是性质，不是声称**：`clone()` 逐个复制每个 slice，
`TestStepDoesNotAliasTheReceiver` 与 `TestObserveAndRecordAttemptDoNotAliasTheReceiver`
让"不别名"成为一条**会失败**的断言，而不是一句注释。

**穷尽性是手写的——因为 Go 的 `match` 不强制穷尽**（Rust 会，这是当初比较两种语言时
记下的那条差异）。`TestEveryPairIsAccountedFor` 枚举全部 165 个 `(state, event)` 对，
把允许边与一份手写清单逐字对比；`TestEveryStateIsReachable` 用 BFS 抓孤儿状态。
**10 个变异测试**（删边、改阈值、改比较符、改结算方式）全部被抓住。

**它不知道自己在哪运行。** `session/` 不 import `core`、不碰文件、不做 I/O——
所以在 shell 适配器里它是从日志重放出来的，将来在 dsh 适配器里也一样。
**这条是"外设可摘换"的第一个真实样本，不是口号。**


### `arbiter/` —— "系统自己发现"必须是性质，不是声称

契约写的是 `P(success) ~ Beta(α+成功, β+失败)`。**照字面实现是不够的**：那是一个
记忆无界的运行平均，一个 1000 次成功的技能腐烂之后，要差不多那么多次坏调用才会
掉下来。所以后验做成**带指数遗忘的折叠**，衰减因子是**显式参数**——它就是这个
系统的灵敏度/特异度取舍，藏起来就等于没做这个决定。

证据是一条会失败的测试，不是一段说明：

| 断言 | 读数 |
|---|---|
| 30 次成功后让它腐烂 | **17 次失败内被弃用**（界 25），没有人通知过仲裁器 |
| 负对照：去掉遗忘 | 25 次失败后均值还有 **0.8855**（有遗忘是 **0.5992**） |
| 记忆确实有界 | 500 次观测后无遗忘计数 **502**，有遗忘 **50.0** |
| 弃用不是永久 | 后验从 **0.023 恢复到 0.645** |
| 毒化项能翻转决定 | 同一笔节省：**E1 = −2415.00（拒绝）vs E4 = +35.00（固化）** |

**探索项不是可选的。** 永远选当前最优会让每个决定都不可逆——一次坏补丁会永久
杀死一个好技能，因为再也没人调它。这就是为什么上界永远高于均值。

`escalation.go` 还有一条命名上的决定：动作**按价格取名不按层级取名**。
`L0/L1/L2/L3` 那套让"哪个模型、跑在哪、谁付钱"全都答不上来，因为"层级"不指代成本。

### 器官之间不互相 import —— 第二次被验证

`memory`、`composer`、`arbiter` 都只依赖 `core` 与 `evidence`，彼此不认识。
在适配器里它们是**同一条链上各自投影自己的记录**（`rec:"session"` / `"memory"` /
`"execution"`），而不是一个调另一个。**把三个器官接起来的那个决定，留给了调度方。**

### `executor/` —— 判定不是执行者自己的事

`plan.go` 从 manifest 的投影（`Declaration`）算出**要跑什么**：argv、入口、stdin、时限、断言。
它**拒绝**它跑不了或不许跑的声明——比如 `budget.ms` 为 0 的，理由是逐字的
「an execution with no declared deadline is an unbounded one」。

`verify.go` 的 `Judge(asserts []string, obs Observed) Judgement` —— **签名本身就是纪律**：
入参里没有「成功了吗」这个位置，执行者没有地方把它自己的意见放进来。
`Observed` 全是别人产生的事实：退出码、是否被时限杀掉、是否根本没启动、收到多少字节、花了多久。
`verified_by` 恒为 `verify_assert`。

**判不了就说判不了**（`VerdictUnknown`），而 `Outcome()` 对它返回 `false`
⇒ 适配器**不写 resolution**，链上留下一条永远开着的 intent。
那不是失败，那是**诚实的第三态**：写 `failed` 是猜，写 `ok` 是骗。经 curl 成立，逐字：

```
"outcome":"unknown","resolution":null
reason":"cannot be judged: 我大概成功了吧（an assertion must start with a field name…）；
 this attempt is left open on the chain on purpose: an open intent IS the honest third state,
 and writing any of the five outcomes here would be a lie"
```

**证据只由真实执行提升**：`Elevate` 只认 `Verdict==ok` 且声明等级恰为 E0，且**只给 E1**；
落地方式是「同一份 payload 以 `evidence=E1` 重新 Register」→ 新 ref、新 manifest hash、
canary 指针移到新 ref —— **不碰 `Promote` 的 E0 闸门**。自报成功不算证据，它还是 E0。

| 约束 | 断言（都在 `drive.sh` 里） |
|---|---|
| 执行者不许自证 | `★ 执行者自报成功：退出码 0` / `★ 核验器仍判失败：声明里那条没做到` |
| 判不了不写结论 | `★ 判不了就不写 resolution（链上留空）` |
| 证据只能真实提升 | `★ 一次真实的成功执行把证据从 E0 提到 E1` / `★ 自报成功不算证据：它还是 E0` |
| 拒绝是值 | `★ 没有声明预算的执行不许开始（A7）` / `★ 被拒的执行在链上一个字节都没写，预算也一分没花` |

**能力边界是显式的**：只实现 `script`（唯一能 spawn 且 `env.network=false` 的形态）。
`algorithm`（出进程就不是同一次执行）、`code`（ABI 带源码不带二进制）、`llm_api`（要联网）、
`rl_policy`（没有策略运行时，只剩自报）、`human`（人的一步是声称不是可核验执行）
—— 五种**都显式拒绝**，理由各不相同。**说清跑不了什么，比假装都能跑更接近可信。**

**四个变异全被抓住**（把「确凿为假」判成 ok；判不了回落到 ok；预算为 0 也放行；
判不了也硬写 resolution）—— 这四条恰恰是这个组件存在的理由，所以它们有牙这件事是被证明的，
不是被声称的。

### `executor/compose.go` —— 「生」这个字

宗旨说 `万物 = AI × 算力 × Skill`。三分之二的因子里，「生」此前一直没做：
技能是孤立的，十个技能就是十种能力——**那是三生十，不是三生万物**。

组合让结果**本身成为一个技能**，于是它可以再被组合。这是宗旨唯一能被证伪的那一条。

`PlanComposition(Composition) (Graph, *core.Refusal)` 把组合算成一张**执行图**：

| 算子 | 形状 | 落地了吗 |
|---|---|---|
| `serial` | `A;B;C` —— 第一步吃组合输入，之后每步吃上一步的输出 | ✅ 默认链 |
| `parallel` | `A‖B` —— 每个孩子都吃组合输入，孩子之间不交换任何东西 | ✅ 扇出 |
| `select` / `conditional` | 需要一个**运行期**求值的谓词 | ❌ 规划器是纯的，求不了 |
| `retry` | 需要每次尝试一条链记录 | ❌ 一次 invoke 一个 intent，重试会丢尝试 |
| `loop` | 需要在迭代间求值的终止条件 | ❌ 光有界不算条件 |

四种拒绝**理由各不相同**——合成一句「不支持的算子」会让人以为换个算子名就能过。

**接线必须与默认形状逐字相符。** 显式 `Wires` 顺序无关（那是图不是文本），
但一条本执行器不去兑现的线会被**拒绝**而不是忽略：

> 接受一条自己不去兑现的线，就是静默丢数据，
> 而静默丢数据的组合会给出一个**看起来正常的错答案**。

`JudgeComposition([]Judgement) Judgement` 不重新求值任何断言。组合的核验不是
「把孩子的输出拼起来再套一遍断言」，而是「每个孩子各自被独立判定过了，组合怎么读这些判定」。
规则按顺序：

1. 没有孩子 ⇒ `unknown`（没有证据不许默认成功）
2. 任何孩子**确凿**不 ok（failed / timeout / refused）⇒ 组合就是那个，取**第一个**
3. 否则任何孩子 `unknown` ⇒ 组合 `unknown`（**部分判不了，整体就判不了**）
4. 否则全部 ok ⇒ `ok`

**第 2 条优先于第 3 条**：一个孩子失败了，组合就已经确定不 ok，
不需要等另一个判不了的孩子。反过来先报 `unknown`，会把一个**已知的失败藏起来**。

**执行器把 ref 当不透明字符串，从不校验哈希格式。** 哈希格式是技能店的事实，
在这里再写一遍就是同一个事实的第二个定义——本项目已为此付过三次学费。
执行器只要求 ref 非空，因为它**从不把 ref 变成路径**，没有注入面。

**9 个变异全部被抓住**：第一步不吃组合输入 / serial 输出取全部 / parallel 变串联 /
判不了排在确凿失败前面 / 任何接线都接受 / 空组合放行 / 没有孩子判 ok /
反着穿边界放行 / 重复接线不查。
