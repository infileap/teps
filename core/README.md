# core/ —— 微内核

**只有"必须唯一权威、必须原子、必须每次经过"三种性质，配得上进这个目录。**

一切其他东西——无论它多重要、多中心、多想当然——都是 `organs/` 里的一个外设。
判据和论证在 [../docs/KERNEL.md](../docs/KERNEL.md)。

## 这里的四个概念

| 概念 | 性质 | 它持有状态吗 |
|---|---|---|
| **Frame** | 每次经过 | ❌ 无状态 |
| **Log** | 唯一权威 | ⚠️ 状态在**盘上**，不在内存 |
| **Budget** | 原子 | ⚠️ 内存只是缓存，日志是真相 |
| **Refusal** | 每次经过 | ❌ 无状态常量表 |

## 为什么是这四个，而不是别的四个

**唯一需要一点内存状态的是 Budget**——而它必须留在这里的理由，正好就是"必须原子"。
判据在起作用，不是人在分配。

## 词汇禁令（Gate 4）

内核源文件里**不许出现上层领域词**：

```
skill  strategy  gain  escalat  arbitrat  compose  evidence  memor  verif
dsh    cordis    harness  plugin
```

理由：**行数超标是症状，领域词泄漏是病因。**
如果"技能""策略""增益"出现在内核里，说明外设的职责漏进来了——
那比行数超了严重得多，而且出现得更早。

⚠️ **这条禁令扫描的是 `.go` 源文件，不是 `.md`。**
所以本文件可以自由地写出这些词来解释禁令，而 `doc.go` 不能——
这不是疏漏，这是有意的：**注释里出现这些词同样算泄漏。**
